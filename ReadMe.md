### 👨‍💻 About Me

I am a **Full-Stack Software Engineer** with a Master's in Science, currently working as an **SDE-2 at Ishgati Technologies (Godspeed Systems)**. I build production AI agent platforms — multi-provider LLM orchestration, RAG, MCP-based tool integration, and agentic SDLC pipelines — alongside React/Next.js frontends and multi-tenant Postgres/Supabase backends.

- 🔭 **Currently building:** **[Saarthi](https://marketplace.visualstudio.com/items?itemName=godspeed-systems.saarthi)** (a VS Code AI agent, superset of Roo Code/Cline) and **[Chaitanya](https://chaitanya.godspeed.systems)** (an AI governance platform with agent-backed SDLC pipelines and an MCP server), plus **Sakhi**, the AI chat inside **[LifeMaker](https://www.lifemaker.space)**.
- 💼 **Previously:** Engineered **[Avkash.io](https://github.com/zero8dotdev/avkash)**, a multi-tenant leave-management SaaS, and owned the core UI of **Godspeed Studio**, a browser-based IDE for the Godspeed Framework — both at Zero8 Dot Dev.
- 💬 **Ask me about:** LLM orchestration, RAG, MCP, agent guardrails, Next.js, TypeScript, Supabase, and system design.
